# Mapa de Sala — primeira versão

Projeto adaptado a partir do `index.html` enviado como referência.

## Estrutura
- `index.html`: estrutura da interface
- `css/style.css`: estilos
- `js/app.js`: lógica, filtros e renderização
- `js/data.js`: dados das aulas (substituir pelos dados da unidade)
- `database/schema.sql`: estrutura inicial para futura utilização com MySQL

## Executar
Abra `index.html` no navegador. Não é necessário servidor para esta primeira versão.

## Próxima etapa
Substituir os registros de `js/data.js` pelos dados reais da unidade e depois conectar o sistema a um banco de dados/API.
